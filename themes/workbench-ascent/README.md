# Workbench Ascent

A light theme tuned for long reading sessions, with a faded 1929 photo of the Col du Galibier
(Agence Rol, public domain, via Wikimedia Commons) at the foot of the sidebar and on the new
thread screen.

To install it, copy `workbench-ascent.json` and `workbench-ascent.jpg` into the `themes` folder of
your T3 home (`~/.t3/userdata/themes`, or `~/.t3/dev/themes` for a development build), then pick
**Workbench Ascent** in Settings › Appearance.
